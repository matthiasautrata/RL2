# Future RL2 Protocol Work

This directory preserves the former evaluation protocol and its RDF vocabulary. SCOPE-2 excludes
Case lifecycle, Requirement tracking, event sourcing, persistence, and re-evaluation workflows
from the normative RL2 language.

The vocabulary remains available temporarily so the existing corpus can be migrated without a
big-bang rewrite. Its use does not establish core conformance.

Preserved workflow scenarios:

- [Use Case 50: Runtime Evaluation](usecases/runtime-evaluation.md) — request/result/Requirement
  lifecycle and Case projection.
